Tone

The house pair: the dark and the light colors of every page that shows no product, such as the cart page, a plain page or the 404. The theme derives every ground and text color from them, as it does for a product, and checks their contrast. A product without colors of its own takes a color derived from this pair, turned to a hue of its own.

Typography

The heading font and the text font, the two scales that enlarge or reduce every heading and every text at once, and the shared recipes of headings, button labels and small labels: case, style, weight and letter spacing. Gloock, the heading font of the preset, has one weight: a heavier Heading weight does not make it bolder.

Settings (11)
SettingValuesDefaultNotes
Heading fontFontGloock 400Used for headings, names and titles. The type sizes are set for Gloock.
Text fontFontInstrument Sans 400Used for body text, buttons, labels and forms, at weights 400 to 700.
Type sizes
Size settings of sections and blocks are fluid: the desktop value applies from 1440px wide, the mobile value at 390px, and the size scales smoothly in between. The announcement bar and the mega menu switch values at the menu breakpoint instead. The two scales below multiply all of them.

Headings
One shared recipe for every display heading in the theme, so a section title, a product card title and a page title all speak with the same voice. Case, slant and weight stack: set all three loud and a heading reads as heavy rather than editorial, whatever the font.

Button labels
One shared recipe for every button label in the theme, so a product card, an add to cart and a footer newsletter all speak with the same voice. Pick the case first, then the letter spacing that case needs: sentence case sits at None or Hairline, uppercase needs Subtle or wider to keep its capitals apart.
Label case
  • Uppercase
  • As typed
As typedAs typed is the shipped default and reads as a contemporary control. Uppercase reads louder and needs the letter spacing raised with it.
Label letter spacing
  • None
  • Hairline
  • Tight
  • Subtle
  • Standard
  • Wide
  • Widest
NoneSentence case labels want None or Hairline. Uppercase labels want Subtle or wider, because capitals are drawn with lowercase sidebearings and collide when set solid. Past roughly Widest a label reads as a stretched banner rather than a button.
Label style
  • Upright
  • Italic
Upright
Labels and small text
One shared case for everything that is neither a heading nor a button: eyebrows, meta lines, tags and badges, price and discount lines, form labels, filters, variant pills, the announcement bar, the footer links and the main menu. Letter spacing follows the case on its own: uppercase keeps each label's spacing, as typed sets it solid.
Label case
  • Uppercase
  • As typed
As typedAs typed is the shipped default and reads quiet and contemporary. Uppercase reads louder and brings its letter spacing with it.
